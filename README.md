# 올팍타임(OLPARK TIME) 시연판

공연·날씨·주차 데이터로 알려주는 올림픽공원 방문·퇴장 타이밍 예보 서비스.
2026년도 공공데이터 활용 경진대회(한국체육산업개발㈜) 출품작의 1단계 시연판입니다.

> 개인 출품작이며 한국체육산업개발㈜의 공식 서비스가 아닙니다.

**시연 주소(임시)**: https://hwowoo.github.io/olpark-time/

## 운영 계획

- **현재(1단계 시연판)**: GitHub Pages에서 정적 웹으로 임시 운영
- **이전 예정**: 공공데이터포털 인증키 발급 후 **AWS 서버리스**(S3+CloudFront 정적 웹, Lambda+API Gateway API 중계, EventBridge 정기 수집)로 이전.
  코드와 배포 설정은 [`backend/`](backend/README.md)에 준비되어 있습니다.
- 서버를 상시 켜 두는 인스턴스 대신 서버리스를 택해, 2028년까지 운영 비용과 관리 부담을 낮춥니다.

## 실행

빌드 과정이 없는 정적 웹입니다.

- 가장 간단한 방법: `index.html`을 브라우저로 엽니다.
- 로컬 서버: `python -m http.server 8123` 실행 후 http://localhost:8123 접속
- 배포: 폴더 전체를 GitHub Pages, Netlify, Vercel 등 정적 호스팅에 올리면 됩니다.

## 기능 (1단계)

| 탭 | 내용 |
|---|---|
| 방문 예보 | 시간대별 혼잡 예보(원활·혼잡·만차), 도착 권장 시각, 비슷한 날의 혼잡 이력, 예측 vs 실제 비교, 정기 이용자 알림 미리보기 |
| 주차 현황 | 선택한 날의 동시 주차 대수 재생, 「주차장 혼잡도 정보」 기반 주차구역 추천 |
| 퇴장 타이밍 | 공연 종료 후 출차 대기 예측, 권장 출차 시각, 모델 vs 실제 출차 비교 |
| 예보 카드 | SNS 공유용 "오늘의 올팍 교통예보" 이미지 생성·저장 |

## 데이터

공공데이터포털 한국체육산업개발㈜ 개방 데이터(이용허락범위 제한 없음):

- 올림픽공원 입출차 정보 (2024년 7월, 동2·남2·북2문) — `analysis/raw/olpark_inout_202407.csv`
- 주차장 혼잡도 정보 — `analysis/raw/parking_congestion.csv`

원본은 CP949 인코딩이며 UTF-8로 변환해 두었습니다. `python analysis/build_data.py`를 실행하면 `data/olpark.js`가 다시 만들어집니다.

## 계산 방법 요약

- **예측**: 기준일을 뺀 "유사일"(같은 행사 규모·같은 요일 유형)의 10분 단위 동시 주차 대수 평균.
  2024년 7월 31일 각각을 나머지 날로 예측했을 때 9~23시 등급 일치율 평균 88.8%(대형 행사일 73%).
- **공연 관람 추정 차량**: 같은 날 15:00~19:30 입차, 20:30 이후 출차, 2.5시간 이상 체류한 차량.
- **출차 대기**: 관람 추정 차량이 종료 후 10분 45%, 10~20분 30%, 20~30분 15%, 30~60분 10% 출차를 시도한다고 가정하고,
  관측 최대 처리량(10분당 268대)을 상한으로 한 대기행렬 계산.
- **등급 기준**: 동시 주차 800대 이상 혼잡, 1,400대 이상 만차 — 시연용 임시값이며 구역별 면수 확보 후 보정 예정.
