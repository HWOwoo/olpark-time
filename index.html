      모델 vs 실제 출차 기록

      실제 출차(10분당) 모델 출차(10분당) 관측 최대 처리량
      계산 방법

      ① 오후 3시~7시 30분에 들어와 아직 주차 중인 차량을 관람 추정 차량으로 셉니다(시연판은 해당일 기록에서 계산).
      ② 이 차량들이 공연 종료 후 10분 안에 45%, 10~20분 30%, 20~30분 15%, 30~60분 10%가 출차를 시도한다고 가정합니다.
      ③ 출차 처리량은 7월 기록의 10분당 최대 출차 대수를 상한으로 두고, 대기 차량 수 ÷ 분당 처리량으로 대기시간을 계산합니다.
      가정값은 2025년 연계 데이터로 보정할 예정입니다.

      오늘의 올팍 교통예보 카드

      공연 팬 커뮤니티·SNS에 공유할 수 있는 이미지를 자동으로 만듭니다.

      2026년도 공공데이터 활용 경진대회 출품 시연판 · 개인 출품작이며 한국체육산업개발㈜의 공식 서비스가 아닙니다.

      운영: 현재 GitHub Pages에서 임시 운영 중이며, 공공데이터포털 인증키 발급 후 AWS 서버리스(실시간 API 연동)로 이전할 예정입니다.
